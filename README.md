# UNCP ACM Web Development Project

This repository contains the web programming project I built in my Web Programming course at UNC Pembroke. The site demonstrates responsive design, DOM manipulation with JavaScript, and backend interaction using MySQL and PHP.

## Technologies Used
- HTML5 & CSS3
- JavaScript (DOM, Events)
- AJAX & JSON
- MySQL & PHP
- Local development via XAMPP

## Features
- Multiple styled pages with responsive layout
- Interactive UI with JavaScript event handling
- Database integration via PHP and MySQL
